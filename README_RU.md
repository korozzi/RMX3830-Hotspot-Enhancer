# RMX3830 Hotspot Enhancer v0.4.0

Функциональный Modern Xposed API 101 модуль для realme C51 RMX3830 / Android 15.

v0.4.0 добавляет реальный пункт **«Расширенные настройки точки доступа»** прямо в экран Wi-Fi hotspot Settings. Через него используются штатные SoftApConfiguration.Builder и WifiManager.setSoftApConfiguration() для изменения поддерживаемых параметров:

- максимум клиентов (1–10);
- диапазон 2,4 / 5 ГГц;
- скрытая сеть;
- автоотключение;
- изоляция клиентов;
- оптимизация диапазона.

Модуль по-прежнему не трогает разделы boot/init_boot/vendor_boot/vbmeta и не изменяет системные файлы. SSID, MAC-адреса и пароль в лог не записываются.

LSPosed scopes: system, com.android.settings.

Изменения применяются только после нажатия «Применить» в новом редакторе.
