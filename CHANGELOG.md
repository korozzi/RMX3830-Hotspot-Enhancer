# Changelog

## 1.0.0 — Public release

- Added native Settings injection for advanced hotspot controls.
- Added connected-device list and live client count.
- Added hostname, IP and MAC display when available.
- Added temporary disconnect.
- Added white list management.
- Added manual white-list enable switch.
- Added black list management and unblock.
- Added configurable device limit.
- Added configurable hotspot idle timeout.
- Added device isolation when supported by the firmware.
- Added native-style buttons, separators and touch feedback.
- Main advanced settings screen uses the full available display.
- Kept stock Realme hotspot settings for SSID, password, security, band, hidden SSID and compatibility.
