# RMX3830 Hotspot Enhancer 1.0.0

First public release.

The project extends the native Realme hotspot Settings page through Magisk + LSPosed-Irena. It adds device management, white/black lists, device limit, idle auto-shutdown and device isolation without a separate launcher application.

Designed around the realme C51 RMX3830 running Android 15 / realme UI.
