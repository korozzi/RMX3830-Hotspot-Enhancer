# RMX3830 Hotspot Enhancer 1.0.0

First public release of RMX3830 Hotspot Enhancer.

## Highlights

The project extends the native Realme hotspot Settings page through Magisk + LSPosed-Irena. It provides device management, white/black lists, client limit, idle auto-shutdown and device isolation without requiring a separate launcher application.

## Compatibility

Designed and tested around the realme C51 RMX3830 running Android 15 / realme UI.
